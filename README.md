# ai-agents-book-series

Материалы цикла статей по книге «AI Agents and Applications» (Roberto Infante, Manning, 2026) для канала @hermesagentru.

Книга в цикле не лежит: она под копирайтом Manning, репозиторий публичный. Ссылка на официальную страницу издателя - в статье. Для работы с текстом книга живёт в локальном RAG-индексе (см. канал, пост про book2rag).

## Структура

```
01-glavy-1-2-fundament-i-prompty/    Главы 1-2: три класса LLM-систем, RAG, промпты
  statya-glava-1.md                  Текст статьи (источник истины)
  materials/                         Схемы и артефакты
02-chasti-3-4-summarizaciya/         Главы 3-4: суммаризация, MapReduce vs Refine, живой замер
...
```

Папки латиницей, нумерация = порядок выхода статей. Публикация: раз в 1-2 дня, пометки в постах `#AI_Agents_and_Applications #глава_N`.

## Схемы

`materials/sch-*.png` - рендеры секций интерактивной схемы `eli5-agent-vs-engine-glava1.html` (открывается офлайн в браузере). В статьях на telegra.ph используются абсолютные ссылки на raw-файлы этого репо.
